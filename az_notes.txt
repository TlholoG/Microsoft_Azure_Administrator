1. Before you can execute Azure CLI commands, you must sign into Azure. To sign in interactively, use az login. 

Run:
az login

If no web browser is available or the web browser fails to open, you can force device code flow with 

Run:
az login --use-device-code.

2. Verify that you're actually logged in

Run:
az account show

3. I have an existing resource group so i check what groups exist so I can select the one I am going to deploy ARM templates to

Run:
az group list --output table

output:
Name                              Location          Status
--------------------------------  ----------------  ---------
TlholoGropu                       uaenorth          Succeeded


4. Creating a deployment group 
az deployment group create \
  --name blanktemplate \
  --resource-group TlholoGropu \
  --template-file $templateFile
