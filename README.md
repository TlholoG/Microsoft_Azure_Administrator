
# Microsoft Azure Administrator — AZ-104 Labs

A hands-on Azure administration and automation repository documenting my practical work while preparing for the **Microsoft Azure Administrator (AZ-104)** certification.

The repository contains Azure labs, **Azure CLI commands, Bash scripting, infrastructure configuration, and administration exercises** covering core Azure services and operational tasks. It is intended to demonstrate practical experience with deploying, configuring, managing, and troubleshooting Azure resources through both the Azure Portal and command-line tools.
