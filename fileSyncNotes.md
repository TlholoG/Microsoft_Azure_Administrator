
6. Quick AZ-104 revision
   If the question asks…	Remember…
   Can I add a second cloud endpoint to one sync group?	No
   Can I add endpoints from different registered servers to one sync group?	Yes
   Can one server participate in several sync groups?	Yes
   Can one server have two endpoints in the same sync group?	No
   Can an unregistered server host a server endpoint?	No
   Must the cloud endpoint's storage account region match the Storage Sync Service region?	Yes
   Must the storage account be in the same resource group as the Storage Sync Service?	Not as a general requirement
   Can a server be registered with two Storage Sync Services simultaneously?	No
